# Nexus Games

Projeto acadêmico de Front-End para um e-commerce de eletrônicos voltado ao universo gamer.

## Páginas

- `index.html`: menu, banner, categorias, destaques, novidades, galeria e rodapé.
- `login.html`: formulário responsivo com validação e feedback visual.

## Tecnologias

- HTML5 semântico
- CSS3 e media queries
- Bootstrap 5.3.8 e Bootstrap Icons
- JavaScript
- jQuery 4.0.0
- LocalStorage para demonstrar carrinho e opção de lembrar e-mail

## Funcionalidades

- Menu responsivo
- Busca e filtro de produtos
- Carrinho lateral com inclusão e remoção de itens
- Galeria com Bootstrap Carousel
- Mensagens com Bootstrap Toast
- Formulário de login com validação
- Exibição e ocultação de senha
- Layout adaptado para desktop, tablet e celular

## Executar o projeto

Depois de baixar ou clonar a pasta publicada no GitHub, abra `index.html` no navegador ou inicie um servidor local dentro da pasta do projeto:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
